# Zenith MC

A Minecraft Java mod (Fabric) that turns Zenith into a spy map for your world: a minimap and world
map with waypoints, a radar, eye modes and more.

This page holds the download only.

## Download

Open [Releases](https://github.com/AlonAI4/zenith-mc/releases/latest) and take the jar for your
Minecraft version:

- `zenith-mc-<version>+26.2.jar` for Minecraft 26.2
- `zenith-mc-<version>+26.3.jar` for Minecraft 26.3

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.19.5 or newer for your Minecraft version.
2. Put [Fabric API](https://modrinth.com/mod/fabric-api) for the same Minecraft version in your
   mods folder.
3. Put the Zenith MC jar in the same mods folder:
   - Mac: `~/Library/Application Support/minecraft/mods`
   - Windows: `%appdata%\.minecraft\mods`
4. Start the Fabric profile in the Minecraft launcher. The mod needs Java 25, which the official
   launcher brings by itself.

Tested with Fabric API 0.161.0+26.2 and 0.163.0+26.3.
